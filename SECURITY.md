# Security reports

The latest source on `main` is the supported development version. The application
is an experimental Windows prototype, with no signed release or automatic updater.

Please do not post exploit details, cookies, credentials, or account data in a
public issue. Use GitHub's **Report a vulnerability** option in the repository's
Security tab when it is available. Otherwise, open an issue requesting a private
contact channel without including the vulnerability details.

The security boundary is the local settings WebView: the remote TikTok WebView
must not gain access to native application commands. Include the affected commit,
Windows version, and minimal reproduction steps in a private report.
